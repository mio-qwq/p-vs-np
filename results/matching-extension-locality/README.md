# Finite ambient-extension test

A function using only internal edge indicators on m distinguished baseline pairs vanishes on every ambient flip-radius-r ball if and only if it vanishes on the ball with m+r baseline pairs. This applies to arbitrary functions of those indicators, and does not say the current characteristic-three exceptional witnesses pass the extension test.
