# Four-row consecutive-exponent masked determinants

For any binary 4-by-4 mask with a perfect matching, any four distinct real offsets a_i, and any integer d >= 0, det[eta_ij (x+a_i)^(d+j)] for j=0,1,2,3 is a nonzero polynomial. The coefficient proof covers all 65,536 labeled masks and 207 nontrivial symbolic classes. It also gives the balanced-support-component corollary stated in the report.

Read `input/REPORT.md` for the theorem and proof, and `AUDIT.md` for the independent symbolic audit, including the smaller-order lemma. The producer regenerates `input/exact_certificate.json`; the independent auditor regenerates `audit_results.json`, including factor-removal and Bézout witnesses. These two large JSON outputs are intentionally absent from the tracked files and source archive. `GENERATED.json` records their expected exact hashes, sizes, and small coverage statistics.

## Scope

This is an auxiliary algebraic result, not a solution of P versus NP. It does not establish order-four gapped exponents or larger matching-covered components. The real-offset assumption matters: a distinct-complex-offset counterexample is verified exactly. Nonzero polynomial does not mean root-free. Novelty is unverified. Independent audits were AI-assisted, not human peer review or proof-assistant verification.

## Reproduce

Use Python 3.10+ and its standard library only. Run the commands in this order from this directory (the producer must run first):

    python3 input/check_consecutive_four.py
    python3 audit_certificate.py
    python3 -O audit_certificate.py

Run the producer with ordinary Python, without `-O` and with `PYTHONOPTIMIZE` unset, because it uses assertions. It regenerates `input/exact_certificate.json`; the audit regenerates `audit_results.json`. To preserve the published files and verify hashes first, instead run from the repository root:

    python3 results/verify-20261018.py

That wrapper uses fresh temporary copies, generates the missing certificate before auditing it, checks both generated output hashes and normal/optimized audit equivalence, and requires all corruption and false-extension controls to behave as expected. It removes inherited `PYTHONOPTIMIZE` for ordinary checker runs.
